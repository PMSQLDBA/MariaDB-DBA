## MariaDB DBA — 10-Lesson Course

| Lesson | Topic                         | What you’ll learn                                                                             |
| ------ | ----------------------------- | --------------------------------------------------------------------------------------------- |
| **1**  | MariaDB Fundamentals          | Architecture, installation, server processes, databases, users, and configuration             |
| **2**  | SQL & Database Management     | `CREATE`, `ALTER`, `DROP`, tables, indexes, constraints, and schemas                          |
| **3**  | Users & Security              | Users, roles, privileges, authentication, password policies, and least privilege              |
| **4**  | MariaDB Configuration         | `my.cnf`, server variables, connections, memory, buffers, logs, and configuration tuning      |
| **5**  | Backup & Restore              | Logical/physical backups, `mariadb-dump`, restore procedures, and backup strategies           |
| **6**  | Replication                   | Primary/replica architecture, GTID, binary logs, replication setup, and troubleshooting       |
| **7**  | Monitoring & Performance      | Slow queries, `EXPLAIN`, indexes, performance metrics, process monitoring, and optimization   |
| **8**  | High Availability             | Failover concepts, MariaDB Galera Cluster, redundancy, and disaster recovery                  |
| **9**  | Maintenance & Troubleshooting | Corruption, crashes, disk problems, locks, replication failures, and recovery                 |
| **10** | Production DBA Operations     | Security hardening, automation, capacity planning, DR, upgrades, and real-world DBA workflows |
